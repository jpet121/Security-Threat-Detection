# Operation, formats and security boundaries

## Supported layouts

- SSH: `[Mon DD HH:MM:SS | ISO_TIMESTAMP] HOST sshd[PID]: MESSAGE`, including a missing timestamp. Default authentication detection requires an explicit `Failed password for ...` or `Failed publickey for ...` message, with `[invalid user ]ACCOUNT from ADDRESS port PORT [sshN] [preauth]`. Successful authentication and unrelated errors do not match. Fingerprint-suffixed or other SSH layouts are not supported by these default rules. Other SSH messages are parsed but are not classified by the default rules. Addresses and server names are recorded fields, not verified attribution.
- Apache/Nginx common or combined: `ADDRESS ident user [DD/Mon/YYYY:HH:MM:SS +ZZZZ] "METHOD TARGET HTTP/N.N" STATUS BYTES ["REFERER" "USER_AGENT"]`. Headers are available only where exported (referer and user-agent for combined). Other exported headers can be provided as console request fields. A raw `#` fragment in an HTTP request target is anomalous and goes to manual review; percent-encoded `%23` is still inspected normally. Escaped quotation/JSON/custom access layouts need a new adapter; rejection is counted rather than guessed. Access records do not supply a backend server identity, so it remains unavailable.
- Application/container: timestamp-prefixed console lines with `key=value` or `key="value with spaces"`. Within double-quoted console values, `\"` and `\\` represent a quote and backslash in the inspection copy. Unknown/dangling escapes, unterminated quotes, duplicate keys, unquoted quotes/backslashes and unexpected non-field text after fields are unclassified for manual review. Empty values are preserved. Fieldless logger labels and indented prose continuations are allowed; a quoted field cannot cross a physical line. Default auth event is exactly `event=organizer_admin_login_failed`. Optional fields: `account`, `ip`, `server`, `service`, `endpoint`, `request.query`, `request.path`, `request.body`, `request.header`, `request.user_agent`, `request.referer`. A leading `container-name | ` prefix is stripped from a processing copy. Indented continuations belong to the preceding record, within the configured event limit; original line ranges remain in findings. Orphan continuations and unknown layouts need manual review. No missing fields are invented. Configure console prefix, boundary and timestamp expressions for known exported layouts.

## Accounting

Each input selection is distinct, including repeat selections and duplicate exports. Each record is exactly one matched, unmatched or time-filtered event. Records examined = unique matched events + unclassified records + filtered records on successful processing. A malformed event is also unclassified and counted in parse failures. Manual-review and unknown-time counts overlap those categories. Physical lines grouped into one multiline record are counted as one record. A compressed failure can occur before a pending event is yielded; source status is then incomplete and processed counts are only lower bounds.

`source_id` joins findings to inventory even if a display-safe/redacted filename differs from the actual name. File hashes identify original bytes, not the redacted representation. Verify source hash and cited lines against protected originals. Source descriptors are opened read-only through no-symlink directory walks; nonregular files, symlinks and unreadable paths produce incomplete inventory entries. Sources are hashed before and after streaming; detected changes prevent completion. An offline immutable collection is still recommended because no user-space reader can prove stability against every adversarial filesystem race.

## Bounds and failure handling

The default line/event limits are 64 KiB/256 KiB; fields 32 Ki characters; URL decode depth 2; each regex operation 20 ms; expanded bytes per file 1 GiB. The SQLite store has a configurable page limit, a 2 MiB cache and disk-backed sorting. Staging size is checked during ingestion; individual report files have the configured disk ceiling. Allow additional space for report copies, SQLite transactions and filesystem overhead. This is not an operating-system disk quota. Configure filesystem quotas externally for a hard total ceiling.

Oversized or undecodable records are cited for manual review. Malformed escapes, normalization bounds and matcher timeouts do not establish a definitive negative. Corrupt archives, I/O errors, source mutation, expansion limits and interrupts are incomplete. Disk failures may prevent even a partial manifest; the partial directory name and non-success exit remain the fallback evidence. Publication first moves artifacts into a sibling directory whose name contains `.partial-`, then atomically commits that whole directory with Linux `renameat2(RENAME_NOREPLACE)`. An existing destination, even an empty directory or symlink, is never replaced. A failed per-file move or commit never creates an unmarked final directory; `publication_partial` in the incomplete manifest cites already-moved artifacts. A crash may leave both partial directories. After a successful atomic commit, a staging-cleanup error can leave an empty/unused staging directory; the final manifest remains authoritative. Unsupported kernels/filesystems fail incomplete with no final directory. Atomic visibility is not a power-loss/fsync durability guarantee.

No log text is passed to shell/process APIs. Audit code imports no network client and never downloads rules or uploads evidence. Install dependencies before disconnecting. The operator must already have read access to local authorized exports; the CLI does not request credentials or privileges.

## Privacy

Known password/token/session/cookie/authorization fields are masked in all ordinary exports. Percent-encoded copies are decoded for safe display, terminal controls are escaped and report text is HTML-escaped. Excessively encoded display strings are masked. JSON Lines is the supported machine export; no HTML or spreadsheet export is generated. Ordinary reports are not secret-free by proof: arbitrary unlabeled secrets, unusual credential labels and sensitive account names can remain. Keep reports confidential, inspect locally before sharing, and retain source evidence under its original access policy. Dedicated output directories are mode 0700; use a secure parent directory and encrypted storage when required.

## Troubleshooting

- Invalid config (64): check required rule metadata, IDs, allowed format/field selectors, TOML and regex syntax; compare with `rules/default.toml`. Nothing is scanned first.
- Output exists: choose a new path. Existing evidence/results are never intentionally overwritten.
- Incomplete (3): inspect the partial manifest inventory/error code; check source permissions, gzip integrity, source stability and limits. Rerun after correcting the cause.
- Warnings (2): inspect `manual_review.jsonl` citations and format/encoding assumptions. The tool cannot safely infer unsupported formats.
- Unknown chronology: supply justified timezone and syslog year or leave unknown. A timezone cannot resolve ambiguous DST times.
